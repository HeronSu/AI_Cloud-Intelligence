# ☁️ AI 云智算架构
---
IT世界的发展，经过了许多阶段。

在2000年左右，此时是**传统数据中心时代**，一台物理服务器往往需要承担一个主要业务。虽然一台服务器理论上也可以运行多个应用，但不同业务之间的资源隔离能力有限，容易产生资源竞争。当某个业务的访问量较低时，服务器的大量计算、存储资源也可能处于闲置状态，导致整体资源利用率较低，企业还需要承担较高的服务器、机房和运维成本。

2000-2010年左右，逐渐进入**虚拟化时代**，虚拟化厂商开发出了很多虚拟化产品，例如VMware Workstation, Microsoft Hyper-V,而IT人员，为了保证业务的连续性，业务不能中断，需要用到企业级虚拟化。虚拟化的出现带来了远远超乎想象的便利：**提高了资源的利用率，降低了成本，管理更加便捷等等**

2006 年-2015 年，逐渐进入**云计算时代**，云计算也开始逐渐开始发展起来，**2006年AWS（亚马逊） 发布 S3、EC2**，正式拉开公有云序幕；国内阿里是最早开始做云计算的，阿里云于2009年成立，公有云在全球快速普及，企业开始从自建机房迁移上云。

从2013至今，进入**云原生时代**，2013年**Docker**诞生，容器技术爆发；2014年，Kubernetes(K8s)开源，2015年CNCF云原生计算基金会成立，标志云原生理念成型，随后企业大规模落地K8s，将其真正使用到实际生产环境中，云原生进入工程普及阶段

人工智能时代，即AI时代。对于AI的研究很早就有，但是真正落地使用是在2022年11月，美国的OpenAI公司正式上线了ChatGPT（基于GPT-3.5），随之到第二年GPT-4上线，随后出现了更多的AI大模型，Claude Code(Anthropic), Gemini(Google),  Deepseek(深度求索）, Kimi-K3（月之暗面），Doubao(ByteDance)

**云计算并不是一个独立存在的技术**。一台服务器需要操作系统，操作系统离不开网络；多台服务器组成集群，又会涉及存储、虚拟化和资源管理；当应用越来越多，容器、云原生、自动化和 DevOps 便开始进入其中。再往后，**人工智能**的发展又带来了新的基础设施需求。大模型需要计算资源，模型服务需要稳定的运行环境，RAG 需要数据和检索基础设施，AI Agent 也需要相应的部署与运维能力。

所以对于当下学习云计算来说，云计算本身并不是一个多新的技术，它更像是一种将计算、存储、网络等 IT 资源进行整合，并以服务形式提供给用户的方式，也是一种商业模式在当下这个AI迅猛发展的趋势下，如何将更好地二者结合，才是应对新一轮技术革命的到来的办法，新的时代，需要新的技术结合，以应对新时代下更加新颖，更加艰难的技术挑战。

So, let's start exploring the world of AI and Intelligent Computing!

# 🐧 Linux云计算运维初级
---
学习云计算，首先需要掌握 Linux。

无论是后续学习 **AI、Docker、Kubernetes（K8s）**，还是学习虚拟化、云服务器、云平台等相关技术，Linux 都是非常重要的基础环境。大量云计算基础设施以及相关的软件和工具，都运行在 Linux 环境之上。因此，掌握 Linux 对于学习云计算来说，是必要的一环，也是非常关键的一环。

在后续的学习过程中，我们会经常进入 Linux 系统进行各种操作，例如软件安装、网络配置、服务管理、日志查看以及故障排查等。因此，Linux 不能只停留在了解基本概念的层面，而是需要逐渐熟悉其使用方式，掌握常用命令和常见配置。

> 本阶段的主要任务，就是建立扎实的 **Linux 基础与云计算运维能力**，为后续学习云计算、虚拟化、容器、Kubernetes 以及 AI 云计算相关技术打下基础。
