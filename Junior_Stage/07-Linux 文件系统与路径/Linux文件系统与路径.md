# Linux&windows文件系统差异

- Windows系统结构：C盘和D盘之间相互独立，每一个盘都是一个独立的目录树
![[Pasted image 20260914210816.png|613]](assets/Pasted%20image%2020260914210816.png)

- Linux系统文件系统结构，所有文件都是一棵目录树，一切从根出发。所有的文件和目录以及命令均分区大小写

> [!tip]
>分区的意义是为了方便管理，安全隔离，灵活扩展等等。

  

# Linux系统的重要目录


|      **目录**      | **描述**                   |
| :--------------: | ------------------------ |
|      **/**       | 根目录（根分区），一切的起点，非常重要      |
|    **/root**     | 超级管理员root用户的家目录          |
|     **/etc**     | 存储系统的配置文件，包括系统配置和程序软件的配置 |
|    **/home**     | 普通用户的家目录所在路径，存放用户的个人数据   |
|     /usr/bin     | 存放普通用户执行的命令，编译过的二进制可执行程序 |
|    /usr/sbin     | 存放超级管理员执行的命令             |
|       /usr       | 安装的软件、数据库等目录重要的子目录       |
|       /var       | 存储系统的日志文件和程序的变化文件        |
|       /tmp       | 程序运行的时候产生的临时数据（数据可以删除）   |
|    **/boot**     | 启动引导分区，保存系统开机要加载的文件      |
|     **/dev**     | 设备文件的存放路径，磁盘、光驱等         |
|    /proc、/sys    | 内存中的数据，做性能调优             |
| /mnt和/media、/afs | 做临时挂载使用（空目录）             |
|       /opt       | 一般存储第三方软件（空目录）           |



# 文件命名规则、相对路径与绝对路径

## 文件命名规则

1. Linux严格区分大小写，不管是文件还是命令
2. Linux文件名最长不得超过255个字符 128个汉字
3. 字符是要有效的，除斜线(/ )之外
	- 不要使用某些特殊的字符在文件或者目录名中
	- 当文件名中有特殊字符时应用引号保护引起来
4. Linux没有扩展名，例如.txt、.repo这些扩展名没有任何意义，仅仅方便用户识别


## pwd 

- `pwd`：这个命令主要用于显示当前完整工作目录
```bash
# 案例1
[root@CentOS network-scripts]# pwd
/etc/sysconfig/network-scripts

# 案例2
[root@CentOS ssh]# pwd
/etc/ssh
```



## 相对路径与绝对路径

>[!caution]
> 做任何操作以后，请看清楚当前工作目录是哪个再去做操作。**很多时候误删文件就是没弄清楚当前在哪个目录**。

- 每一个目录下都有两个特殊的目录
    - **`.`** 当前目录
    - **`..`** 上一级目录

- 绝对路径：从根目录开始去表示一个路径
```bash
# 面对这种目录深度很多的时候，需要简便一点
mkdir -p a/b/c/d/f/g/h/i

# 后面这个是绝对路径
cp /etc/passwd /opt/a/b/c/d/f/g/h/i/
```


- 相对路径：以当前目录作为起点来表示路径
```bash
# 后面这个是绝对路径
[root@CentOS i]# cp /etc/shadow .

[root@CentOS i]# ls
passwd shadow
```

> [!tip]
> 路径使用建议
> - 相对路径：在执行命令过程中，尽可能使用相对路径，较为简洁
> - 绝对路径：在脚本中，一定要使用绝对路径。例如Shell脚本，Yaml
