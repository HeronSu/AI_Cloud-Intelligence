# 文本编辑器

> [!tip]
> 在Linux中一切皆文件

## 主要命令

- 主要命令：`vi` & `vim`
    - 如果使用的最小化安装，只有`vi`的软件包，没有`vim`
    - 如果是图形化界面，可以使用`vi`和`vim`，但是二者仍然有差别
> [!important]
> `vi`和`vim`的区别在于**颜色高亮和语法检测**
> - 颜色高亮指的是文件内容的颜色，语法检测指的是文件内容的语法，例如yaml shell脚本，会提示语法错误。但是用法和快捷键都是一样的。

例如：同时用`vi`和 `vim`打开`/etc/resolv.confg`，并对文件进行修改
- `vim`打开，文件中的语法错误会显示颜色高亮，这也是`vim`的区别于`vi`的地方，做语法检测
![[Pasted image 20260913201817.png|662]](assets/Pasted%20image%20260913201817.png)

- `vi`打开，并没有颜色高亮，也没有语法检测
![[Pasted image 20260913201837.png|681]](assets/Pasted%20image%20260913201837.png)

- 用`vim`和`vi`打开文件时有两种情况
	1. 打开一个不存在的文件，即打开一个新文件，左下角会显示`"<file name>" [New File]`
	2. 打开一个存在的文件，文件本身有内容，只会在左下角显示`"<file name>"`




# 执行命令小技巧

## 命令补全

- 命令、文件名、目录名等都可以tab键补齐
> [!note]
> - 注：如果输入的关键字不唯一，tab键无法补全，且会在下面显示包含关键字的文件

- 例如下面这个案例
```bash
[root@CentOS ~]# vim /etc/ssh/ssh
ssh_config                sshd_config               ssh_host_ecdsa_key.pub    ssh_host_ed25519_key.pub  ssh_host_rsa_key.pub
ssh_config.d/             ssh_host_ecdsa_key        ssh_host_ed25519_key      ssh_host_rsa_key
```


## 快捷方式

> [!caution]
> 这里的快捷方式，大部分针对的Linux图形化界面，对于SSH桌面大部分是不适用的

- `ctrl + shift + '+' ` 扩大字体 这个只针对图形界面的终端适用
- **`ctrl -`** 缩小字体
- **`win ↑`** 铺满屏幕
- **`ctrl c`** 中断
- **`ctrl u`** 剪切光标前面的所有的内容
- **`ctrl k`** 剪切光标后面的所有的内容
- **`ctrl y`** 粘贴刚刚剪切的内容
- **`ctrl w`** 删除光标前面的字母
- **`ctrl l`** 清屏（较为常用）
- **`ctrl a`** 移动光标在最左边（较为常用）
- **`ctrl e`** 移动光标在最右边（较为常用）
