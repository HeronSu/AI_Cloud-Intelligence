# 文本编辑器

> [!tip]
> 在Linux中一切皆文件


## 主要命令

- 主要命令：`vi` & `vim`
    - 如果使用的最小化安装，只有`vi`的软件包，没有`vim`
    - 如果是图形化界面，可以使用`vi`和`vim`，但是二者仍然有差别
> [!important]
> `vi`和`vim`的区别在于**颜色高亮和语法检测**
> - 颜色高亮指的是文件内容的颜色，语法检测指的是文件内容的语法，例如yaml shell脚本，会提示语法错误。但是用法和快捷键都是一样的。

例如：同时用`vi`和 `vim`打开`/etc/resolv.confg`，并对文件进行修改
- `vim`打开，文件中的语法错误会显示颜色高亮，这也是`vim`的区别于`vi`的地方，做语法检测
![[Pasted image 20260913201817.png|662]](assets/Pasted%20image%2020260913201817.png)

- `vi`打开，并没有颜色高亮，也没有语法检测
![[Pasted image 20260913201837.png|681]](assets/Pasted%20image%2020260913201837.png)

- 用`vim`和`vi`打开文件时有两种情况
	1. 打开一个不存在的文件，即打开一个新文件，左下角会显示`"<file name>" [New File]`
	2. 打开一个存在的文件，文件本身有内容，只会在左下角显示`"<file name>"`






## 文本编辑器的工作模式及切换

### 三种工作模式

**1. 命令模式**：用于文件的导航，剪切和粘贴，和简单的命令。
- 特点：光标在文本内容里
- 主要用法： 
    - 复制    
	- 粘贴
    - 删除
    - 快速跳转到指定行....

**2. 插入模式**：用于正常的文本编辑
- 特点：在vim编辑器的左下角显示`-- INSERT --`

**3. 退出模式**：用来保存，退出，并打开文件，以及搜索和替换和其他更复杂的操作。
- 特点：光标在左下角，快捷键**shift+:，显示 ：**
- 主要用法：
    - 保存文件
    - 退出文件
    - 另存为文件
    - 快速跳转
    - 替换关键字



### 切换工作模式

1. 由命令模式切换到编辑模式
> 这里`i`键最为常用 

| 按键  | 描述                 |     |
| --- | ------------------ | --- |
| i   | 在光标所在处进入insert     |     |
| o   | 光标下一行进入insert      |     |
| a   | 在光标后一个字符进入insert   |     |
| I   | 在光标所在行的头部进入insert  |     |
| O   | 在光标所在行的上一行进入insert |     |
| A   | 在光标所在行的最末尾进入insert |     |

2. 其他切换模式

## 常见基本操作

- 文本编辑器
    - 按”i”键进入插入模式
    - 修改文本内容
    - 按**`ESC`**键返回
![[Pasted image 20260913202000.png|669]](assets/Pasted%20image%2020260913202000.png)



-  命令模式&退出模式下常见基本操作
	- `:wq`  保存并退出
	- `:x` **等同于**`:wq`
	- `:q` 退出，如果文件被修改又没有保存，系统会提示你
	- `:q!`  **强制退出，不保存
	- `:wq!` 强制保存并退出

> [!caution]
> - 如果打开文件后，没有对文件进行任何操作，**不要`:wq`**，你以为你没有修改，可能文件已经被修改，而进行了保存操作，会对文件进行损坏。会修改文件的时间戳
> - 如果修改文件后，没有对文件进行报错，是无法进行退出的，可以用`:wq!`强制退出，**但是不建议这么做**


- 行号与高亮显示
	- `:set nu`：显示行号
	- `:set nonu`：不显示行号
	- `:set paste` 设置为粘贴模式，如果不设置的话，粘贴过来的内容格式排版会很乱
	- `:set nopaste` 取消设置为粘贴模式
	- `:set nohlsearch`： 不显示颜色高亮
	- `:set cursorcolumn` ：显示列项高亮
![[Pasted image 20260914193243.png]](assets/Paste%20image%2020260914193243.png)


- 文本处理相关操作

| 操作类型 |     操作键     | 功能                                |
| :--: | :---------: | :-------------------------------- |
|  删除  | `x` 或 `Del` | 删除光标处的单个字符                        |
|      |    `dd`     | 剪切当前光标所在行                         |
|      |    `Ndd`    | 剪切光标所在行以及下面 N-1 行                 |
|      |    `:%d`    | 清空文件所有内容                          |
|  复制  |    `yy`     | 复制当前光标所在的行                        |
|      |    `Nyy`    | 复制当前 N 行整行的内容到剪贴板                 |
|  粘贴  |     `p`     | 将缓冲区中的内容粘贴到光标位置处之后                |
|  撤销  |     `u`     | 按最近一次的操作进行撤销，多次重复按`u`键，恢复经进行的多步操作 |
| 文本查找 |    /word    | 从上而下在文件中查找字符串“word”               |
|      |      n      | 定位下一个匹配的被查找字符                     |
- `:noh`：取消当前查找的高亮显示

> [!tip]
>文本编辑器还有一些特殊用法，方便我们日常进行使用

- 多行注释
	- `ctrl v` 进入列高亮选定
	- 向上或向下移动光标，选定要注释的行
	- 按**大写**`I`切换到编辑模式
	- 添加注释符号 **`#`**
	- `Esc`退出

- 批量删除注释
	- `ctrl v` 进入列高亮选定
	- 向上或向下移动光标，选定要注释的行
	- 按`x`删除
	- 添加注释符号 `#`




## 常见问题

> [!important]
> 使用文本编辑器时会出现的问题

- 原因：先按**`q`**再按`:`，会出现vim的历史记录
	- 解决办法：快捷键`shift + :q`，退出历史记录，再`shift + :wq / q`

![[Pasted image 20260913203753.png]](assets/Pasted%20image%2020260913203753.png)



- `vim`打开文件发现无法打开

![[Pasted image 20260913203931.png]](assets/Pasted%20image%2020260913203931.png)

> [!note]
> - **第一种情况***：多个人同时打开这个文件，后面打开的就提示这个信息
> 	- 解决办法：让其他用户关闭这个文件的vim编辑界面
> - **第二种情况**：文件修改了但是没有保存意外退出，再次打开就会出现这个情况
> 	- 按R恢复，则再次打开这个文件就是显示你之前修改文件的内容，并进行保存
> 	- 再删除\.swap的交换文件，按D删除，再保存退出。
> - 如果是在swap文件中打开然后编辑并且保存，再次打开这个源文件则内容是已经修改过的
 >- 如果打开swap文件，按r恢复，则再次打开这个文件就是显示你之前修改文件的内容

- 解决办法
	- 按`R`恢复到编辑的状态，再按`Enter`继续进入编辑界面
	- 但是由于再次打开仍然有这个提示，所以要删除这个临时文件，按`D`键删除`.swap`文件

## 命令补全

- 命令、文件名、目录名等都可以tab键补齐
> [!note]
> - 注：如果输入的关键字不唯一，tab键无法补全，且会在下面显示包含关键字的文件

- 例如下面这个案例
```bash
[root@CentOS ~]# vim /etc/ssh/ssh
ssh_config                sshd_config               ssh_host_ecdsa_key.pub    ssh_host_ed25519_key.pub  ssh_host_rsa_key.pub
ssh_config.d/             ssh_host_ecdsa_key        ssh_host_ed25519_key      ssh_host_rsa_key
```


## 快捷方式

> [!caution]
> 这里的快捷方式，大部分针对的Linux图形化界面，对于SSH桌面大部分是不适用的

- `ctrl + shift + '+' ` 扩大字体 这个只针对图形界面的终端适用
- **`ctrl -`** 缩小字体
- **`win ↑`** 铺满屏幕
- **`ctrl c`** 中断
- **`ctrl u`** 剪切光标前面的所有的内容
- **`ctrl k`** 剪切光标后面的所有的内容
- **`ctrl y`** 粘贴刚刚剪切的内容
- **`ctrl w`** 删除光标前面的字母
- **`ctrl l`** 清屏（较为常用）
- **`ctrl a`** 移动光标在最左边（较为常用）
- **`ctrl e`** 移动光标在最右边（较为常用）
