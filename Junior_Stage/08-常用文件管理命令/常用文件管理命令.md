# 1.cd

> **change directory 切换目录**

- `cd ..` 回到上一级目录
- `cd -`   回到上一次所在的目录
- `cd | cd ~`    回到当前用户的家目录

# 2. ls

# 3. cp

> Copy 复制

- 基本用法
```bash
# 主要语法格式
cp <source path or file> <dest path or file>

# 复制文件
cp /etc/passwd /opt

# 复制文件并改名
cp /etc/passwd /opt/passwd.txt

# 复制文件夹，加上-r参数，递归复制
cp -r /etc/ /opt/
```

> [!important]
> 当使用`cp`命令拷贝文件时，相当于是在另外一个目录下创建了一个新的文件，这个时候，这个文件的权限以及时间戳其实都是重新定义的，与被复制文件是完全不一样的。
> ```bash
> [root@CentOS ~]# ll /etc/passwd
-rw-r--r--. 1 root root 2548 Jan 24  2026 /etc/passwd
[root@CentOS ~]# cp /etc/passwd .
[root@CentOS ~]# ll passwd
-rw-r--r--. 1 root root 2548 Sep 17 21:07 passwd
[root@CentOS ~]#
> ```
> **所以针对需要保留权限和时间戳的场景，使用下列参数。**



- 备份文件时，保留权限和时间戳
```bash
# 源文件权限
-rw-r--r--. 1 root root 2548 Jan 24  2026 /etc/passwd

# 保留权限和时间戳
cp -p /etc/passwd /opt/

# 查看文件，权限和时间戳一致
ll /opt/passwd
-rw-r--r--. 1 root root 2548 Jan 24  2026 /opt/passwd


```
> 这种情况是为了防止文件权限不一致，可能会导致后期文件出现问题，即使还原原始权限，也无法打开的情况


- 复制快捷文件本身
```bash
cp -d /sbin/vgchange /tmp/
```


- `cp -a`融合了 -d -p -r参数的功能，即递归复制目录，保留权限和时间戳并复制快捷文件本身

# 5. rm 

> remove 移除，删除
- 基本用法，不添加任何删除，对某一个文件进行删除，系统会询问你是否进行删除
```bash
# 主要语法格式，会以交互式确认文件是否删除
rm <file or diretory name>

# y为"Yes"，n为"No"
[root@centos opt]# rm file1.txt
rm: remove regular empty file 'file1.txt'? y
```


- 强制对某个文件进行删除
```bash
# 递归强制删除
rm -rf file1.txt

-f: force 强制
-r： 递归
```


> [!warning] 警告
> - 千万不要执行 `rm -rf /*` ，一旦执行，整个系统就会被破坏，几乎无法还原
> - 执行删除命令的时候，一定要查看当前在哪个目录下，删除对应文件名或者目录名的路径一定要写对。



  
# 6. rmdir

>remove directory 删除目录 

- rmdir 删除空目录
```bash
# 只能对空目录进行删除，目录中有内容的话是无法对该目录进行删除
rmdir a/
```


- 应用场景
```bash
[root@centos ~]# cd /sys/fs/cgroup/
```
> 这个目录是存放在内存中，作用是对系统调优的。

> [!tip]
> - 创建文件夹夹后，本应是空目录，但是该目录下有内容
> - `rm -rf` 无法对该目录进行删除，但是rmdir可以对该目录进行删除

# 9. stat

- **`stat`** 查看文件完整时间戳
	- 最后一次访问文件的时间：**Access**
	- 最后一次修改文件属性（文件大小，权限，拥有人拥有组）的时间：**Modify**
	- 最后一次更改文件内容的时间：**Change**
	- 文件的创建时间：**Birth**
```bash
[root@CentOS ~]# stat /etc/passwd
  File: /etc/passwd
  Size: 2548            Blocks: 8          IO Block: 4096   regular file
Device: fd00h/64768d    Inode: 68000551    Links: 1
Access: (0644/-rw-r--r--)  Uid: (    0/    root)   Gid: (    0/    root)
Context: system_u:object_r:passwd_file_t:s0
Access: 2026-09-13 11:01:01.690837964 +0800 # 这个时间可以精确到了纳秒
Modify: 2026-01-24 11:19:10.499025572 +0800
Change: 2026-01-24 11:19:10.500025552 +0800
 Birth: -
```


- 每个文件都有三个时间戳
    - `Access`：文件最后一次访问的时间，当Modify和Chang时间比Access时间要新一些，则查看文件时Access时间会改变，或者24小时变更一次
    - `Modify`：文件最后一次修改的时间
    - `Change`：文件状态最后一次变更的时间，文件状态即文件大小，权限，文件名，拥有人，拥有组等

# 10. file


- file 查看文件类型
```bash
# 空文件
touch hello
file hello

hello: empty` ------->空文件

# 文本文件
[root@centos opt]# echo "hello world" >> hello`**
[root@centos opt]# file hello
hello: ASCII text`------>文本文件

[root@centos opt]# file bak/

bak/: directory`----->目录

[root@centos boot]# file initramfs-0-rescue-5679561dab624534aaeaf9d240fc50e9.img

initramfs-0-rescue-5679561dab624534aaeaf9d240fc50e9.img: ASCII cpio archive (SVR4 with no CRC)`-------->该文件为一个使用cpio的压缩文件
```

# 11. cat

- 查看文件内容，输出文件内容
- 基本用法
```bash
# 当文件有内容时，会输出对应内容
[root@CentOS opt]# echo hello > test.txt
[root@CentOS opt]# cat test.txt
hello

# 当文件没有内容时，以空行代表没有内容
[root@CentOS opt]# echo > test.txt
[root@CentOS opt]# cat test.txt

[root@CentOS opt]#
```
