# 打包与压缩
## 打包

- 打包：将一个或者多个文件打包为一个包文件，也可以称为归档文件
- 打包的特点
	- 打包可以保留文件的属性信息
	- 一个包文件中会包含很多个文件，如果将这些文件一个一个传输，会比较麻烦，进行打包传输效率更高，方便传输
- 包文件后缀通常为`.tar`

>[!tip]
>核心命令：`tar`，下面进行具体解释

**1. 打包**

- `-c`：打包，也可以理解为创建归档文件
- `-f`：指定包文件名，这里可以路径也可以直接接具体文件名
>通常会将`-cf`联合使用，就是正常对文件打包的操作

- 对文件进行打包，命令最后可以接上多个文件
```bash
tar -cf etc_passwd_group.tar /etc/passwd /etc/group
```

这里出现的信息提示是因为没有使用相对路径，但是这里可以忽略，不影响正常使用
```bash
tar: Removing leading `/' from member names
tar: Removing leading `/' from hard link targets
```

- 通过`file`命令查看文件类型，可以看到是一个`tar archive`，归档文件
```bash
[root@CentOS opt]# file etc_passwd_group.tar
etc_passwd_group.tar: POSIX tar archive (GNU)
```

---
**2. 解包**

- 核心选项：`-xf`，默认是解包到当前目录下，如果要指定目录，加上选项`-C`（大写）
```bash
tar -xf etc_passwd_group.tar
```

解包后，会将这些文件都放在一个目录下
```bash
[root@CentOS opt]# ls
etc  etc_passwd_group.tar
[root@CentOS opt]# ll etc
total 8
-rw-r--r--. 1 root root 1023 Sep 29 21:35 group
-rw-r--r--. 1 root root 2589 Oct 16 15:53 passwd
```

---
**3.查看包文件内容**

>[!tip]
>有时候，用户不想先解压，想先看一下包文件里面有哪些内容

- 核心选项：`-tf`
```bash
tar -tf etc_passwd_group.tar
etc/passwd
etc/group
```

- 如果想看到更详细的信息，加上`-v`选项
```bash
[root@CentOS opt]# tar -tvf etc_passwd_group.tar
-rw-r--r-- root/root      2589 2026-10-16 15:53 etc/passwd
-rw-r--r-- root/root      1023 2026-09-29 21:35 etc/group
```


## 压缩

>[!tip]
>常说的压缩包，实际上是两步操作，先打包后压缩

- 压缩：字面理解，就是要对文件大小进行压缩
- 压缩包：先打包为一个包文件，再对包文件进行压缩，最后就是压缩包


- 主要有三种压缩工具：这里面使用最多的其实只有两个，`gzip`和`xz`
	- `gzip`：后缀为`.tar.gz`
	- `bzip2`：后缀为`.tar.bz2`
	- `xz`：后缀为`.tar.xz`

- 用一个工具来演示压缩
```bash
[root@CentOS opt]# gzip etc_passwd_group.tar
[root@CentOS opt]# ll
total 8
drwxr-xr-x. 2 root root   33 Nov 19 21:03 etc
-rw-r--r--. 1 root root 1552 Nov 19 20:59 etc_passwd_group.tar.gz
```

>[!note]
>三种压缩工具中，gzip压缩的时间最短，压缩比例也是最小的，bzip2其次，压缩时间最长的是xz，压缩比例是最大的

- 对应的有三个解压缩工具
	- `gunzip`
	- `bunzip2`
	- `unxz`

- 这些工具的使用方法十分简单，只需要在命令后加上对应的包文件和压缩文件即可完成压缩和解压缩
```bash
[command] <tar archive >
```

- 演示对目录压缩，提示为目录文件，进行忽略
```bash
[root@CentOS opt]# gzip etc
gzip: etc is a directory -- ignored
```

>[!important]
>压缩只能对于文件压缩，不能针对目录文件压缩，如果非要对目录文件压缩，按照如下步骤进行
>- 先对目录文件打包为一个包文件
>- 再对包文件进行压缩

- 上面提到的都是单一工具，但是`tar`可以在打包的同时进行压缩，选项如下
	- **`-z`** ：使用gzip压缩
	- **`-j`** ：使用bzip2压缩
	- **`-J`**： 使用xz压缩

>[!note]
>案例1：需要将`/etc/passwd`文件进行打包压缩，压缩后的文件路径`/opt/etc-passwd.tar.gz`

- 打包同时压缩
```bash
tar -zcf /opt/etc-passwd.tar.gz /etc/passwd
```

查看下压缩文件，以及压缩文件类型
```bash
tar: Removing leading `/' from member names
[root@CentOS opt]# ll
total 4
-rw-r--r--. 1 root root 1128 Nov 19 21:27 etc-passwd.tar.gz
[root@CentOS opt]# file etc-passwd.tar.gz
etc-passwd.tar.gz: gzip compressed data, last modified: Thu Nov 19 13:27:05 2026, from Unix, original size 10240
```

>[!note]
>案例2：需要将`/etc/passwd`文件进行打包压缩，压缩后的文件路径`/opt/etc-passwd.tgz`

- 这里说的`.tgz`与`.tar.gz`本质上是一致的，都是使用gzip来进行压缩的
```bash
tar -zcf /opt/etc-passwd.tgz /etc/passwd
```


>[!note]
>案例3：将`/opt/etc-passwd.tgz`解压缩操作，解压缩的同时解包，将解压后的文件放到`/tmp`目录下

- 解压缩并解包放到指定目录
```bash
tar -zxf etc-passwd.tar.gz -C /tmp
```

```bash
[root@CentOS opt]# tar -zxf etc-passwd.tar.gz -C /tmp/
[root@CentOS opt]# cd /tmp/
[root@CentOS tmp]# ll
total 0
drwxr-xr-x. 2 root root 20 Nov 19 21:29 etc
```

>[!important]
>如果压缩文件使用的是上面提到的三种工具进行压缩的，可以直接用下面的命令进行解压缩并进行解包，因为直接执行就会去调用对应的工具进行解压缩
>```bash
>tar -xf <file>
>```
