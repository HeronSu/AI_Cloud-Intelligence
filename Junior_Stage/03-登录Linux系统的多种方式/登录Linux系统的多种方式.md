# 基于命令行登录

- 实际上是通过字符页面登录。
    - 如果是最小化安装，默认就是字符界面。
    - 如果是图形化界面，要想切换到字符界面，可以使用键盘的快捷方式。
    - 字符界面输入密码时，没有明文显示，但是实际上已经输入进去了

> [!important] 
> - 在Linux系统中，纯字符界面也是一个完整的Linux系统
> - 图形化界面是在字符界面的基础上运行了一个图形的应用程序软件，即使没有图形界面也没有问题



# 终端切换以及界面设置

- 系统中一共提供了6种虚拟控制台
> **控制台：ctrl \+ alt \+ F\[1\-6\]   2个图形控制台\+4个虚拟控制台**

- 有的笔记本可能切换不了，请你观察一下是否拥有Fn键
    - 首先如果安装了图形化桌面，第一个虚拟控制台永远是图形化的登录页面，第二个虚拟控制台是图形化页面
    - **如果没有安装图形化桌面，所有的虚拟控制台都是字符页面**
    - 原来的时候，没有图形化，要想执行多个命令，一个虚拟控制台无法执行



2. 默认每次开机自动进入字符界面
**`# systemctl set-default multi-user.target`**


3. 默认每次开机自动进入图形界面（前提：**系统安装时，已经安装了图形界面**）
**`# systemctl set-default graphical.target`**

> [!note]
> 关于终端切换，根据实际需要进行选择，做个人学习使用的话
> - 如果安装的是GNROM图形化界面，一般情况下不需要图形化界面，但是如果遇到图形化界面卡顿，可以使用字符界面进行替代
> - 如果安装的是纯字符界面，默认就没有图形化界面，但是在此种界面下，不建议切换至其他的终端来执行




# 基于网络SSH

> 这种连接方式最为常见

- 通常情况下，你不会直接面对服务器去管理机器。通过网络的方式来远程管理服务器
- 如果网络可以正常通信，通过ssh命令来实现远程登录，只不过所有的命令都是基于命令行操作，没有图形化而且你也看不到图形化
- 下面使用SSH连接的方式有以下几种形式
    - 使用Windows系统自带的cmd或者Powershell
    - 使用SSH连接工具，例如xshell，MobaXterm


> [!caution]
> 这里只介绍基本用法，具体的SSH连接会在后续的内容中学到

- 具体步骤如下：将虚拟机和windows端进行网络互通，虚拟机网络ip地址进行手动修改(自动获取IP地址)，windows虚拟机网络ip进行修改(或者直接ifconfig获取虚拟机ip地址）

![[Pasted image 20260913160945.png|677]](assets/Pasted%20image%2020260913160945.png)



- 打开windows端cmd，在cmd命令行中输入` `**`ping+ ip地址`**，确认是否互通。输入命令：ssh 用户名@（ip地址）

![[Pasted image 20260913161003.png|666]](assets/Pasted%20image%2020260913161003.png)

> [!Tip]
注：用户名可以是普通用户，或者是超级用户root（**但需要在创建root用户时勾选允许通过ssh登录**1）






# 基于cockpit控制台登录

> Linux操作系统可以通过浏览器的方式来进行管理，可以鼠标点点点来操作

- 在Linux行中输入
```bash
systemctl  enable --now cockpit.socket
``` 


- 在浏览器中输入：（ip地址）：9090
![[Pasted image 20260913161114.png]](assets/Pasted%20image%2020260913161114.png)


> [!caution]
> **CentOS 8\.4版本中，允许root用户登录到该平台，如果此时不允许root用户登录**，又需要root用户通过控制台登录`/etc/cockpit/disallowed-users`，删除root

![[Pasted image 20260913161122.png]](assets/Pasted%20image%2020260913161122.png)

> [!caution]
