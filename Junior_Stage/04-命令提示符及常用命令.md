# 1.命令行提示符详解

```Linux
[root@CentOS ~]#
```
- root为当前登录系统的用户
- `@`为分隔符 
- CentOS为主机名的短格式（若要查看长格式 `hostname`命令查看）
> [!example]
eg.完整的主机名，长格式**CentOS\.example\.com**\(FQDN 完全限制主机名\)

- `~`表示当前用户的工作目录，如果是`~`为家目录，如果为其他目录，即显示为当前的目录
> 家目录本质上也是一个目录，只不过相较于其他目录来说，较为特殊

- 特权提示符（**`#/$`**）：如果是**`#`**表示是超级管理员root用户，如果是**`$`**表示是普通用户

## useradd & id 
---
> 这里`useradd`的使用这里只做基本介绍，在后续用户管理部分，会详细进行介绍

> [!caution]
> useradd创建用户操作**只能由管理员进行操作**，这是管理员的特权

- 创建用户：`useradd`
```Linux
# 命令格式如下
useradd <username>

# 创建用户
[root@CentOS ~]# useradd zhangsan
```

- 判断用户是否存在：`id`
	- 判断依据，是否输出用户的uid，gid，groups信息
``` Linux
# 命令格式如下
id <username>

# 判断用户是否存在
[root@CentOS ~]# id zhangsan
uid=1001(zhangsan) gid=1001(zhangsan) groups=1001(zhangsan)

# 当用户不存在，存在会显示uid，gid，groups
[root@CentOS ~]# id lisi
id: ‘lisi’: no such user 
```


> 附加`whoami`
- 从字面上理解，就是我是谁，输出结果为当前用户名
```bash
[root@CentOS ~]# whoami
root
```



## passwd

> 用于修改密码

1. 直接对用户修改密码
``` bash
# 修改密码
passwd <username>

# 案例：为张三用户修改密码
passwd zhangsan passwd 

Changing password for user zhangsan.
New password:
BAD PASSWORD: The password is a palindrome
Retype new password:
passwd: all authentication tokens updated successfully.
```


2. 利用管道符来修改密码
- 通过`echo`命令的输出结果来作为修改密码的结果
```bash
echo 1 | passwd --stdin zhangsan

Changing password for user zhangsan.
passwd: all authentication tokens updated successfully.
```

> [!tip]
> 这里管道符的使用，后面会详细提到，这里简单提一下



3. 特殊情况：对于普通用户来说，**无法修改其他用户的密码，只能修改自己的密码**
>相反，root作为超级管理员，拥有最高权限，可以对所有用户修改密码
```bash
$ passwd zhangsan
passwd: Only root can specify a user name.

# 对张三用户修改密码，发现密码
$ passwd
Changing password for user zhangsan.
Current password:
New password:
BAD PASSWORD: The password fails the dictionary check - it is too simplistic/systematic
passwd: Authentication token manipulation error
```

- 上面对密码检查有字典检查的方式，主要是密码破解有下列方法
	- 暴力破解：穷举所有可能的字符组合，理论上一定能覆盖，但组合空间可能非常大
	- 字典攻击：使用常见密码、单词、泄露密码等进行尝试，比纯暴力更高效
> [!caution] 普通用户的密码要求十分苛刻
> 1. 密码长度不能少于8位
> 2. 密码必须包含一定数量的不同字符类别，包括：
> 	- 至少一个小写字母
> 	- 至少一个大写字母
> 	- 至少一个数字
> 	- 至少一个特殊字符（非字母数字字符）
> 3. 密码不能是字典中的单词，也不能是简单的模式。
> 4. 密码不能与之前的密码相同（系统会记住最近几次的密码，默认可能是5次）。
> 5. 密码不能与用户名相似。

## su

> 该命令主要用来切换用户

- 命令格式
```bash
# 命令格式如下
su - <username>

# 如果su后面不接用户名，默认是切换到root用户
su - 
# 等价于
su - root
```


1. 对于**管理员root**来说，切换到任何用户不需要密码
```bash
# 从root切换到zhangsan用户
[root@CentOS ~]# su - zhangsan
[zhangsan@CentOS ~]$
```



2. 但对于**普通用户**来说，切换到任何用户都需要密码
```bash
[zhangsan@CentOS ~]$ su - root
Password:

[zhangsan@CentOS ~]$ su - lisi
Password:
```

3. 如果要从当前用户退出，执行下列命令
```bash
exit
```
> 退出终端界面，也可以使用该命令

- 像这种不加`-`的来切换用户的，会导致很多问题
	- 虽然当前用户切到了user，但是当前工作目录为root的家目录，会出现**权限问题**，在命令执行的时候可能会频繁报错
	- 也有可能导致环境变量错乱
```bash
[root@CentOS ~]# su user
[user@CentOS root]$
```
> [!warning] 注意
> 这种命令形式不建议使用，**建议仍然按照`su`常规切换用户方式进行切换**


## hostname & hostnamectl

> 查看主机名和修改主机名

- 查看当前主机名
```bash
$ hostname
CentOS.example.com  # 这个是完整的主机名(FQDN)，即长格式
```

- 修改当前主机名
```bash
# 修改主机名，这里的主机名可以是完整的FQDN,也可以是短格式，例如centos，根据需要进行调整
hostnamectl set-hostname centos.example.com

# 刷新一下，重新加载
bash

# 再次查看主机名，可以看到已经被修改了
$ hostname
centos.example.com
```

- 历史记录保存的上限是1000条，在`/etc/profile`文件中有记录
```bash
# 文件中存在如下字段，上限为1000条
HOSTNAME=`/usr/bin/hostname 2>/dev/null`
HISTSIZE=1000
```
> 如果超过了历史记录的上限，那么会覆盖掉前面的记录，1001条记录，第1条就会被覆盖掉。每一个用户的历史记录上限都是1000

> [!caution]
历史记录的保存上限不是越多越好，一旦系统被入侵，系统上所有操作的命令都会被看到


- 如果想看到具体什么时间敲的什么命令，在**`.bashrc`**文件中添加这个内容
```bash
vim .bashrc

export HISTTIMEFORMAT="%F %T"
```


- 临时删除历史记录
```bash
history -c
```

> [!tip]
**重启或者再次登录到该系统后，历史记录仍然存在，因为这个数据已经被写入到磁盘中**


- 想要真正清除历史记录，有两种办法
    - 删除`~/.bash_history` 文件，**不推荐**
    - 执行 **`echo > .bash_history`** 
> [!warning] 
> 历史记录的存在也增加了系统的安全隐患
> - 对于路由器和交换机的历史记录来说，是存放在内存中，重启设备后所有命令的历史记录都会被清除
>- 但是对于Linux系统来说，重启后历史记录仍然存在，在每一个用户的家目录下，都有对应的\.bash\_history，用户一旦注销，所有命令历史记录都记录在该文件中


## date & timedatectl & cal

> 这三个命令与时间日期都有关系

- `date`：用于查看日期
```bash
# 查看日期
date

# CST为中国标准时间，即北京时间
Mon Sep 14 07:45:51 CST 2026
# 日期显示为周、月、日，时分秒，年，现在的时区为CST

# 按照特定方法进行输出，例如显示年月日，时分秒
date +'%Y-%m-%d %H:%M:%S'
2025-12-21 15:28:35
```

> [!example]
> ```bash

> %s seconds since 1970-01-01 00:00:00
> 
> # 一天是86400秒

> 
> # 备份/etc/，`$(date -d '1 day ago' +%Y%m%d)`引用命令执行结果，日期为一天前
> cp -r /etc/ /backup/etc-$(date -d '1 day ago' +%Y%m%d)`



- 修改日期
```bash
# 将计算机的时间修改为2026年09月15日 18:25:26
date [-u|--utc|--universal] [MMDDhhmm[[CC]YY][.ss]]

# 具体参数解释
MM：月
DD：日
hh：小时
mm：分钟
CC:年份的前两位，例如2026，CC即为20
YY：年份的后两位，例如2026，YY即为26
ss：秒

# 查看帮助是这么写的，但是这种写法过于复杂，也不容易记住
date 091518252026.26

# 推荐这种形式来对日期时间进行修改
date -s "2025-03-15 16:57:20"

```



- `timedatectl`：修改时区
```bash
# 更改时区
timedatectl set-timezone "Asia/Shanghai"`
```

## 计算器

> Linux系统提供了一个类似Windows的计算器，区别在于这个属于命令行下的计算器

- 直接进入计算器
```bash
# 直接进入计算器
bc
bc 1.07.1
Copyright 1991-1994, 1997, 1998, 2000, 2004, 2006, 2008, 2012-2017 Free Software Foundation, Inc.
This is free software with ABSOLUTELY NO WARRANTY.
For details type `warranty'.
# 直接在此处输出对应内容

```

- 基本运算
```text
+   加
-   减
*   乘
/   除，这里的除法是整除，和C语言中的保持一致
%   取余
^   幂
```

```bash
# 加法
1+2+3+4+5
15

# 减法
10-2-3-4
1

# 乘法
1*2*3*4
24

# 整除
10/2
5
2/4
0
3/2
1

# 求余
3%2
1

乘方
2^10
1024
```


- 计算小数
使用 `scale` 指定小数位数
```bash
# 保留两位小数
scale=2
100/3
33.33

# 保留三位小数
scale=3
1/8
.125
```

> [!tip]
> 这里保留三位小数的操作，实际结果应该是0.125，但是这里输出。125，`bc`的输出格式中，**当小数的整数部分为 0 时，不显示这个 `0`**。


- 退出计算器
```bash
quit
```

- 在shell中使用，即结合`echo`命令，将输出结果作为计算的算式
```bash
# 算式用双引号引用，通过管道符来进行输出
echo "10+20"| bc
30

# 算式中的多个条件，用分号隔开
echo "scale=2;100/3" | bc
33.33
```
